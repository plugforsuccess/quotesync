## Event Payload Structure

### Standard Fields (All Events)

```typescript
interface NewsroomEvent {
  // Supabase (story_analytics table)
  id: UUID;                    // Auto-generated by database
  story_id: UUID;              // FK to stories.id
  event_type: EventType;       // Enum: see below
  user_session_id: string;     // Client-side session ID
  referrer: string | null;     // document.referrer
  cta_type?: string;           // Optional: which CTA was clicked
  metadata: Record<string, any>; // Additional context
  created_at: timestamp;       // Auto-generated by database

  // External (GA4 / Meta Pixel)
  story_id: UUID;              // Same as above
  story_title: string;         // From story object
  story_category: string;      // From story object
  ...metadata                  // Spread additional fields
}
```

### Event Types

```typescript
type EventType =
  | 'feed_view'          // User lands on /news
  | 'story_impression'   // Card enters viewport (50%+)
  | 'video_play'         // Video starts playing
  | 'video_complete'     // Video finishes
  | 'read_more_open'     // "Read more" clicked
  | 'cta_click'          // CTA button clicked
  | 'share_click';       // Share button clicked
```

## Session ID Generation

### Implementation
```javascript
// src/lib/newsroomAnalytics.js
const getSessionId = () => {
  let sessionId = sessionStorage.getItem('newsroom_session_id');

  if (!sessionId) {
    sessionId = `session_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
    sessionStorage.setItem('newsroom_session_id', sessionId);
  }

  return sessionId;
};
```

### Characteristics
- **Scope:** Per-tab (sessionStorage, not localStorage)
- **Lifetime:** Until tab closed
- **Format:** `session_1704672000000_a3b5c7d9e`
- **Privacy:** No PII, not tied to user accounts
- **Purpose:** Group events within a single browsing session

## Event Deduplication Strategy

### Problem: Multiple Fires

**Scenario 1: Impression Tracking**
```
User scrolls slowly past story card
↓
IntersectionObserver fires multiple times
↓
Could track same impression 5+ times
```

**Scenario 2: Video Play**
```
Video buffers and restarts
↓
onPlay event fires twice
↓
Could double-count video plays
```

### Solution: Client-Side Deduplication

#### Story Impressions
```javascript
// StoryCard.jsx - Lines 45-71
const [hasTrackedImpression, setHasTrackedImpression] = useState(false);

useEffect(() => {
  if (hasTrackedImpression) return;  // ← Dedupe guard

  const observer = new IntersectionObserver(
    (entries) => {
      entries.forEach((entry) => {
        if (entry.isIntersecting && !hasTrackedImpression) {
          trackStoryImpression(story);
          setHasTrackedImpression(true);  // ← Set flag, never fire again
        }
      });
    },
    { threshold: 0.5 }  // 50% visible
  );

  // Cleanup observer when component unmounts
}, [story, hasTrackedImpression]);
```

**Result:** Story impression tracked **exactly once** per page load

---

#### Video Play Events
```javascript
// StoryCard.jsx - Lines 74-79
const [videoPlaying, setVideoPlaying] = useState(false);

const handleVideoPlay = () => {
  if (!videoPlaying) {  // ← Dedupe guard
    trackVideoPlay(story);
    setVideoPlaying(true);
  }
};
```

**Result:** Video play tracked **exactly once** per story per session

## Preventing Double-Fire (GA4 / Meta)

### Current Implementation
```javascript
// src/lib/newsroomAnalytics.js
const trackNewsroomEvent = async (storyId, eventType, metadata = {}) => {
  // 1. Track to Supabase
  await supabase.from('story_analytics').insert({...});

  // 2. Track to GA4/Meta (single call)
  trackEvent(`newsroom_${eventType}`, {...});
};

// src/lib/analytics.js
export const trackEvent = (eventName, eventParams = {}) => {
  // GA4
  if (window.gtag) {
    window.gtag('event', eventName, eventParams);  // ← Single call
  }

  // Meta Pixel
  if (window.fbq) {
    window.fbq('track', eventName, eventParams);   // ← Single call
  }
};
```

### Verification
```javascript
// Test in browser console
let gaCallCount = 0;
let originalGtag = window.gtag;

window.gtag = function(...args) {
  if (args[0] === 'event' && args[1].startsWith('newsroom_')) {
    gaCallCount++;

  }
  return originalGtag(...args);
};

// Scroll to story → Should see "GA4 call #1"
// Scroll back → Should NOT see "GA4 call #2"
```

## Future Enhancement: Referrer Code Tracking

### Implementation Plan
```javascript
// Parse referrer code from URL
const getReferrerCode = () => {
  const params = new URLSearchParams(window.location.search);
  return params.get('ref') || params.get('utm_source') || null;
};

// Store in sessionStorage
const referrerCode = getReferrerCode();
if (referrerCode) {
  sessionStorage.setItem('newsroom_referrer_code', referrerCode);
}

// Include in all analytics events
const trackNewsroomEvent = async (storyId, eventType, metadata = {}) => {
  const referrerCode = sessionStorage.getItem('newsroom_referrer_code');

    event_type: eventType,
    user_session_id: sessionId,
```

## Analytics Query Examples

### Top Stories by Impressions (Last 7 Days)
```sql
SELECT
  s.title,
  s.category,
  COUNT(*) as impression_count
FROM story_analytics sa
JOIN stories s ON sa.story_id = s.id
WHERE sa.event_type = 'story_impression'
  AND sa.created_at > NOW() - INTERVAL '7 days'
GROUP BY s.id, s.title, s.category
ORDER BY impression_count DESC
LIMIT 10;
```

### Conversion Funnel
```sql
WITH funnel AS (
  SELECT
    story_id,
    COUNT(*) FILTER (WHERE event_type = 'story_impression') as impressions,
    COUNT(*) FILTER (WHERE event_type = 'video_play') as video_plays,
    COUNT(*) FILTER (WHERE event_type = 'read_more_open') as read_mores,
    COUNT(*) FILTER (WHERE event_type = 'cta_click') as cta_clicks
  FROM story_analytics
  WHERE created_at > NOW() - INTERVAL '7 days'
  GROUP BY story_id
)
SELECT
  s.title,
  f.impressions,
  f.video_plays,
  ROUND(f.video_plays::numeric / NULLIF(f.impressions, 0) * 100, 2) as video_rate,
  f.read_mores,
  ROUND(f.read_mores::numeric / NULLIF(f.impressions, 0) * 100, 2) as read_rate,
  f.cta_clicks,
  ROUND(f.cta_clicks::numeric / NULLIF(f.impressions, 0) * 100, 2) as conversion_rate
FROM funnel f
JOIN stories s ON f.story_id = s.id
ORDER BY f.impressions DESC;
```

### Session Analysis
```sql
SELECT
  user_session_id,
  COUNT(DISTINCT story_id) as stories_viewed,
  COUNT(*) FILTER (WHERE event_type = 'video_play') as videos_played,
  COUNT(*) FILTER (WHERE event_type = 'cta_click') as ctas_clicked,
  MIN(created_at) as session_start,
  MAX(created_at) as session_end,
  EXTRACT(EPOCH FROM (MAX(created_at) - MIN(created_at))) / 60 as session_duration_minutes
FROM story_analytics
WHERE created_at > NOW() - INTERVAL '24 hours'
GROUP BY user_session_id
HAVING COUNT(*) > 3  -- Active sessions only
ORDER BY stories_viewed DESC;
```

## Data Retention Policy

### Supabase Analytics
- **Retention:** Indefinite (unlimited storage)
- **Aggregation:** Raw events stored, no pre-aggregation
- **Archival:** Consider moving to cold storage after 1 year

### GA4
- **Retention:** 14 months (default)
- **Extension:** Can extend to 26 months in settings

### Meta Pixel
- **Retention:** 7 days (conversion window)
- **Aggregation:** Aggregated data retained longer
